## Best Practices for Alt-Text
- **Be Specific:** Describe the actual visual elements.
- **Include Keywords naturally:** Don't keyword stuff; incorporate them into the description.
- **Keep it under 125 characters:** Most screen readers cut off after this length.
- **Avoid "Image of" or "Picture of":** Screen readers already identify it as an image.
