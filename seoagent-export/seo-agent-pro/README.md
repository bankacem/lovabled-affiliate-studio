# 🤖 SEOAgent Pro – وكيل مقالات SEO احترافي متكامل بـ LangGraph و Groq

هذا المجلد يحتوي على وكيل الـ SEO المتكامل والذكي لتوليد مقالات SEO احترافية ومحسنة بالكامل لمحركات البحث ولظهور الذكاء الاصطناعي (AI Overviews) بشكل آلي بالكامل ومجاني.

---

## ✨ ميزات الوكيل الذكي (SEOAgent Pro):
1. **التحليل والبحث الحي**: يقوم بالبحث الحقيقي والآلي عبر الويب باستخدام DuckDuckGo دون الحاجة لمفاتيح API مدفوعة.
2. **استراتيجية المحتوى الفائقة**: يعد مخطط E-E-A-T متكامل مع العناوين والكلمات المفتاحية الفرعية (LSI) ومطابقة نية المستخدم بدقة.
3. **الكتابة الاحترافية والتحسين الآلي**: كتابة مسودات المقالات وتحسين كثافة الكلمات المفتاحية وبنية الـ Schema والفقرات.
4. **التقييم الذاتي والدورات التكرارية**: يقيم نفسه ويقوم بإعادة المحاولة والتصحيح حتى 3 مرات للوصول للدرجة المطلوبة (أكثر من 85%).
5. **التعلم الذاتي المستمر**: يمتلك ذاكرة للمهارات يتولد فيها ملف `memory/skills.md` تلقائيًا ويتعلم من كل دورة لتجنب الأخطاء السابقة وتدعيم نقاط القوة.
6. **التكامل التام مع GitHub Actions**: يدعم النشر التلقائي والدفع التلقائي للمقالات المنتجة إلى المستودع ليقرأها موقعك فورًا على Vercel.

---

## 📂 الهيكل المجلد الذكي:
- **`config.py`**: إعدادات النظام، النماذج، والدرجة المطلوبة للتقييم.
- **`seo_agent.py`**: الكود البرمجي الرئيسي للوكيل (LangGraph + Groq).
- **`requirements.txt`**: المكتبات المطلوبة للتشغيل.
- **`outputs/`**: المجلد الذي تتولد فيه المقالات النهائية كملفات Markdown محسنة.
- **`memory/`**: مجلد التعلم والذاكرة لتحديث المهارات.

## 🛠️ التشغيل المحلي (للإختبار والتطوير):

### 1. تثبيت المتطلبات:
تأكد من وجود بيئة Python 3.10 أو أحدث، ثم قم بتثبيت المكتبات:
```bash
pip install -r requirements.txt
```

### 2. إعداد مفتاح API الخاص بـ Groq:
احصل على مفتاح مجاني وسريع من [Console Groq](https://console.groq.com/)، ثم قم بتهيئته في جهازك:

- **على أنظمة Linux/macOS:**
  ```bash
  export GROQ_API_KEY="gsk_xxxxxxxxxxxxxx"
  ```
- **على نظام Windows (CMD):**
  ```cmd
  set GROQ_API_KEY=gsk_xxxxxxxxxxxxxx
  ```

### 3. تشغيل الوكيل:
قم بتشغيل السكريبت وسيطلب منك إدخال الكلمة المفتاحية واللغة:
```bash
python seo_agent.py
```

## 🚀 التشغيل التلقائي عبر GitHub Actions:
لقد قمنا بإضافة Workflow متكامل في جذر المستودع `.github/workflows/generate.yml` لتشغيل هذا الوكيل بضغطة زر.

### خطوات التشغيل والتهيئة على GitHub:
1. اذهب إلى مستودعك على GitHub.
2. توجه إلى **Settings** ➔ **Secrets and variables** ➔ **Actions**.
3. أضف سرًا جديدًا (New Repository Secret) باسم **`GROQ_API_KEY`** واجعله يحتوي على مفتاح Groq الخاص بك.
4. اذهب إلى تبويب **Actions** في الأعلى، ستجد Workflow باسم **"توليد مقالة SEO احترافية"**.
5. اضغط على **Run workflow**، واكتب الكلمة المفتاحية (مثال: `أفضل طرق تعلم البرمجة في 2026`) واللغة (افتراضياً `Arabic`) ثم اضغط زر التشغيل.

سيقوم الـ Action بتشغيل الوكيل وتوليد المقال بالكامل مع تدقيق ذاتي وذاكرة مهارات، ومن ثم دفعه تلقائيًا إلى مجلد `outputs/` في مستودعك!
