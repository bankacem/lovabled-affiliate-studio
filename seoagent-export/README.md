# دليل تشغيل وكيل الـ SEO (.seoagent) في مشروع Chrome Extension Booster 🚀

هذا المجلد يحتوي على كافة الملفات والتعليمات اللازمة لتشغيل وكيل الـ SEO وتدقيق المقالات وتوليد التقارير في مشروعك الجديد.

---

## 📂 محتويات الحزمة:
1. **`seo-audit-seoagent.ts`**: محرك التدقيق والتحليل البرمجي (مكتوب بلغة TypeScript).
2. **`content/`**: مجلد يحتوي على نموذج لمقالة بصيغة Markdown للبدء فوراً وتجربة الأداة.
3. **`README.md`**: هذا الدليل التفصيلي للتشغيل والإعداد.

---

## 🛠️ خطوات الإعداد والتشغيل في مشروعك الجديد:

### الخطوة 1: نسخ الملفات
قم بنسخ مجلد `.seoagent` إلى المجلد الرئيسي (Root) لمشروعك الجديد:
- تأكد من وجود مجلد باسم `.seoagent` في جذر المشروع الجديد وبداخله مجلد `content` الذي يحتوي على المقالات المراد تدقيقها.

### الخطوة 2: نسخ سكريبت التدقيق
قم بنسخ سكريبت التدقيق `seo-audit-seoagent.ts` وضعه في أي مكان في مشروعك الجديد (مثلاً داخل مجلد `scripts/` أو المجلد الرئيسي).

### الخطوة 3: تثبيت الحزم المطلوبة
افتح الطرفية (Terminal) في مشروعك الجديد وقم بتثبيت الأدوات المطلوبة لتشغيل TypeScript بسهولة (إذا لم تكن مثبتة بالفعل):
```bash
npm install -D typescript tsx @types/node
# أو باستخدام pnpm:
pnpm install -D typescript tsx @types/node
# أو باستخدام yarn:
yarn add -D typescript tsx @types/node
```

### الخطوة 4: إضافة أمر التشغيل إلى `package.json`
افتح ملف `package.json` في مشروعك الجديد، وقم بإضافة السطر التالي في قسم `"scripts"`:
```json
"scripts": {
  "audit-seo": "tsx scripts/seo-audit-seoagent.ts"
}
```
*(تأكد من تعديل المسار `scripts/seo-audit-seoagent.ts` إذا قمت بوضع السكريبت في مكان آخر).*

### الخطوة 5: تشغيل الوكيل وتوليد التقارير
الآن، لتشغيل التدقيق ومعرفة جودة المقالات وتوليد تقرير كامل، فقط اكتب الأمر التالي في الطرفية:
```bash
npm run audit-seo
# أو
pnpm run audit-seo
```

سيقوم الوكيل فوراً بقراءة المقالات من مجلد `.seoagent/content` وتحليلها وتوليد تقرير تفصيلي شامل باللغة العربية باسم `audit_report.md` داخل مجلد `.seoagent`!
