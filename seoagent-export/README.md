# 🚀 حزمة وكيل الـ SEO المتكامل (SEOAgent)

مرحباً بك في حزمة الـ SEO المتكاملة لمشروعك! يحتوي هذا المجلد على أدوات وحلول احترافية لتدقيق وتوليد مقالات الـ SEO ومتابعة جودة المحتوى تلقائياً وبأعلى كفاءة.

---

## 📂 محتويات الحزمة الرئيسية:

### 1. ⚙️ نظام تدقيق المقالات (TypeScript)
نظام برمجي مخصص لتدقيق صفحات ومقالات الموقع، وتحليل جودتها وتوليد تقارير شاملة باللغة العربية.
- **الملف الرئيسي**: `seo-audit-seoagent.ts`
- **مجلد المحتوى**: `content/` الذي يحتوي على مسودات ومقالات الـ Markdown للبدء فوراً.
- **طريقة التشغيل**:
  1. قم بتثبيت التبعيات: `pnpm install -D typescript tsx @types/node`
  2. أضف سكريبت التشغيل في `package.json`: `"audit-seo": "tsx seoagent-export/seo-audit-seoagent.ts"`
  3. شغّل التدقيق وتوليد التقارير: `pnpm run audit-seo`

---

### 2. 🤖 وكيل مقالات الـ SEO الذكي (Python + LangGraph)
وكيل ذكي متكامل يعمل بـ **الذكاء الاصطناعي التفاعلي** باستخدام **LangGraph + Groq** لتوليد وتحسين المقالات ذاتياً والتعلم المستمر، مع دعم النشر التلقائي عبر **GitHub Actions**.
- **المجلد الخاص بالوكيل**: [`seo-agent-pro/`](./seo-agent-pro/)
- **الميزات الرئيسية**:
  - البحث الحي والمجاني في الويب عبر DuckDuckGo.
  - التقييم الذاتي والتكرار الذكي حتى الحصول على أعلى درجة جودة.
  - ذاكرة المهارات والتعلم التلقائي المتراكم (`skills.md`).
  - النشر التلقائي إلى المستودع بضغطة زر عبر GitHub Actions.
- **طريقة التشغيل**: تفضل بزيارة دليل التشغيل التفصيلي في [صفحة المجلد الخاص بالوكيل الذكي](./seo-agent-pro/README.md).
