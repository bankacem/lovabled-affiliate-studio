# وكيل SEO محمول (.seoagent) — قابل للنقل لأي مشروع 🚀

مجلد مستقل تمامًا: انسخه لأي مشروع Node.js جديد ويعمل بنفس الطريقة، طالما توفّر
Node + مفاتيح API القليلة الموضحة أدناه. لا يعتمد على Supabase أو أي بنية تحتية
خاصة بمشروع معيّن.

---

## 📂 محتويات الحزمة

1. **`write-article.ts`**: الوكيل الكاتب — بحث المنافسين + الكتابة + التقييم والتصحيح الذاتي، كل ذلك في سكربت واحد.
2. **`seo-audit-seoagent.ts`**: محرك التدقيق البرمجي (فحص قواعد مجاني فوري لأي مقال Markdown).
3. **`content/`**: المقالات (نموذج ابتدائي + أي مقال يُنشئه `write-article.ts` يُحفظ هنا تلقائيًا).
4. **`README.md`**: هذا الدليل.

## 🖊️ الوكيل الكاتب — `write-article.ts`

### ماذا يفعل بالضبط
```
1. بحث حقيقي في جوجل عن أفضل 3 نتائج للكلمة المفتاحية (عبر Serper.dev)
2. تحليل نقاط ضعف هذه النتائج فعليًا (وليس تخمينًا)
3. كتابة مقال يستهدف تحديدًا استغلال تلك النقاط
4. تقييم فوري مجاني (عدد كلمات، عبارات AI مبتذلة، FAQ، بنية العناوين)
   + سؤال ذكاء اصطناعي واحد فقط: هل عُولجت فجوات المنافسين فعلاً؟
5. إن كانت النتيجة ضعيفة: إعادة كتابة واحدة فقط بتغذية راجعة محددة، ثم توقف
6. حفظ المقال كملف Markdown في content/ بنفس الصيغة التي يقرأها seo-audit-seoagent.ts
```

بسيط عمدًا: لا حلقات لا نهائية، لا إطار عمل (framework) إضافي، فقط استدعاءات
مباشرة لنفس مفاتيح الـ API التي تملكها أصلاً.

### الإعداد
```bash
npm install -D tsx @types/node   # أو pnpm/yarn المعادل
```

### المفاتيح المطلوبة (متغيرات بيئة)
| المتغير | إجباري؟ | الوظيفة |
|---|---|---|
| `OPENROUTER_API_KEY` | أحدهما إجباري | الكتابة + التحليل (يُفضَّل إن وُجد) |
| `GROQ_API_KEY` | أحدهما إجباري | بديل إن غاب OpenRouter |
| `SERPER_API_KEY` | اختياري | يُفعّل بحث المنافسين الحقيقي — بدونه يكتب الوكيل مباشرة بدون هذه الخطوة، بصدق، بدون تحليل وهمي |
| `OUTPUT_DIR` | اختياري | افتراضيًا `./content` |

### التشغيل
```bash
OPENROUTER_API_KEY=sk-... SERPER_API_KEY=... npx tsx write-article.ts "best hiking backpacks 2026"
```

الناتج: ملف `.md` جاهز داخل `content/`، بصيغة متوافقة تمامًا مع أداة التدقيق أدناه.

## 🔍 أداة التدقيق — `seo-audit-seoagent.ts`

### الإعداد في مشروع جديد
1. انسخ مجلد `.seoagent` كاملاً لجذر المشروع الجديد.
2. تأكد من تثبيت الحزم:
```bash
npm install -D typescript tsx @types/node
```
3. أضف سطرًا في `package.json`:
```json
"scripts": {
  "audit-seo": "tsx .seoagent/seo-audit-seoagent.ts"
}
```
4. شغّله:
```bash
npm run audit-seo
```

سيقرأ كل المقالات من `content/` (بما فيها أي مقال أنشأه `write-article.ts` تلقائيًا)
ويولّد `audit_report.md` بتقرير عربي مفصّل لكل مقال.
